# Plataforma de Monitoreo de Red

Sistema web para el monitoreo de dispositivos en una red local, con escaneo automático, historial, alertas y analítica.

---

## 🚀 Tecnologías utilizadas

### Backend
- Python
- Flask
- Flask-SocketIO
- MySQL

### Frontend
- HTML
- CSS
- JavaScript

### Análisis de datos
- NumPy
- Scikit-learn

---

## ⚙️ Funcionalidades

- Escaneo de dispositivos en la red local
- Registro histórico de escaneos
- Detección de nuevos dispositivos
- Sistema de alertas
- Clasificación y gestión de dispositivos
- Escaneo automático programado
- Dashboard con métricas y analítica
